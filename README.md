# Team Task Manager ✅

🚀 **Live Demo:** [https://team-task-manager-steel-tau.vercel.app/](https://team-task-manager-steel-tau.vercel.app/)

A full-stack web application designed to help teams efficiently manage, assign, and track the progress of their projects and tasks.

## Features
* **Role-Based Access:** Distinct Admin and Member roles with secure JWT authentication.
* **Project Management:** Admins can quickly create and delete projects.
* **Task Tracking:** Create tasks, set priorities (Low, Medium, High), and establish deadlines.
* **Interactive Dashboard:** Real-time statistics dynamically tracking Pending, In Progress, and Completed tasks.
* **Responsive Design:** Clean, modern UI accessible from desktop or mobile.

## Tech Stack
* **Frontend:** React, Vite, React Router, Axios
* **Backend:** Node.js, Express, JSON Web Tokens (JWT)
* **Database:** MongoDB (Mongoose)
* **Deployment:** Vercel (Frontend), Railway (Backend)

## Run Locally

**1. Clone the repository:**
```bash
git clone https://github.com/YOUR_GITHUB_USERNAME/team-task-manager.git
cd team-task-manager
```

**2. Run Backend:**
```bash
cd backend
npm install
npm run dev
```

**3. Run Frontend (in a new terminal):**
```bash
cd frontend
npm install
npm run dev
```
